# 근거자료와 예측 모델 관리

## 목적

초음파 계측·형태와 성장 이력을 바탕으로 성장 단계와 바이오밴딩 평가를 우선 지원한다. 예상 성인키는 의료진이 검토·조정하는 보조 추정이다. 완전한 예측을 전제하지 않으며, 확보한 근거를 비교하고 추적 결과에 따라 모델을 개선한다. 현재 모델이 가장 정확하거나 확률적으로 보정되었다고 검증 없이 주장하지 않는다.

## 한 곳에서 관리

- 원문 보관: `data/sources/` (기존 11개 자료).
- 등록 목록과 파일 해시: `data/manifest.json`.
- 검색용 페이지: `data/pages.json`.
- 성장도표 수치: `data/growth.json`.
- 새 원문·보충자료도 sources에 보관하되, 보관과 계산에 채택하는 것은 구분한다. 환자 검진자료는 이 폴더에 넣지 않는다.
- 현재 새 파일을 복사하는 것만으로 앱에 자동 반영되지 않는다. 기존 ingest.py는 정렬 순서로 출처 ID를 다시 부여하므로 새 자료 추가 시 그대로 재실행하지 않는다. 기존 인용 ID를 보존하는 등록 절차가 필요하다.

## 방법별 채택 기록

각 방법에 원문 파일·DOI·페이지/표, 예측 대상(골연령/PHV/성장종료/성인키), 촬영 부위·측·단면, 길이비/면적비 등 입력 정의, 공식·계수·단위, 성별·연령·대상 집단, 검증 대상과 오차, 적용 한계, 구현 버전 및 채택 상태를 기록한다. 상태는 원문 미확보 → 원문 확보 → 계산 재현 → 적용 검토 → 추적 검증으로 구분한다. 보고서·강의·홍보 자료를 동등한 검증 근거로 취급하지 않는다.

## 출력 정책

성장 단계가 주 평가 항목이다. 앱은 아래 정책을 적용한다. 실제 환자에 대한 예측 성능은 아직 검증되지 않았다.

- 예상키의 AI 중심 구간은 약 3cm 폭과 중간값으로 표현하되, 근거 부족이나 큰 불확실성을 감추기 위해 폭을 강제하지 않는다.
- pre-PHV·가속기의 중간값 −1.5cm ~ +5.5cm는 사용자 지정 운영 범위다. 검증된 예측구간 또는 포함 확률로 표시하지 않는다.
- 자료로 계산된 값, AI 종합 추정, 사용자 지정 범위, 의료진 수정값을 분리한다.
- 확률·정확도는 해당 예측 대상과 대상 집단에서 측정한 근거가 있을 때만 제시한다. X-ray 골연령과의 상관계수를 최종키 정확도로 바꾸지 않는다.
- 이전 예측값은 이번 추정의 정답으로 사용하지 않는다.

## 결과 설명 문안

본 결과는 확보된 연구·계측·성장 이력을 바탕으로 현재의 성장 단계와 예상 성인키를 추정하는 스포츠 성장평가 보조 자료입니다. 적용 방법과 자료의 한계에 따라 오차가 있으며, 의료진이 원본 영상과 추가 변수를 검토해 최종 판단합니다. 추적 측정 결과를 통해 오차와 구간 포함률을 평가하고 개선합니다.

예측이 실제 결과와 다를 수 있다는 점은 검증을 면제하지 않는다. 골연령, PHV 시점, 실제 성인키를 각각 해당 관찰 결과와 비교한다. 모델 버전별 편향·평균절대오차·구간 포함률을 기록하고, 성별·성장 단계별 성능을 별도로 확인한다. 다른 프로그램의 예측키와 일치하는 것만으로 실제 성인키 정확도를 입증하지 않는다.
