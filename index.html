WORKSPACE GUIDE

평가를 시작하는 방법

기록과 근거를 확인하며 의료진의 판단을 정리합니다.

01. 자료 입력

검진 메모를 붙여넣으면 기본 정보와 이전 회차 기록이 자동 입력됩니다. 검사일을 확인하고 척골·요골·대퇴골 원위부 사진을 각 3–5장 추가하세요.

첨부파일에서 읽은 값은 AI 결과의 ‘추출 기록’에 표시됩니다. 기본 계측란을 자동으로 덮어쓰지 않습니다.

02. 수치와 근거

완료 월령에 해당하는 2017 성장도표의 신장·BMI 백분위 구간을 비교합니다. 이전 측정이 있으면 연환산 성장속도를 표시합니다.

현재 신장 백분위는 생물학적 성숙도나 바이오밴딩군을 뜻하지 않습니다.

03. AI 연결

AI 연결 설정은 서비스 관리자가 서버에서 관리합니다. API 키는 브라우저에 저장하지 않습니다.

AI는 성별에 맞는 연령별 참고영상과 이번 초음파 사진을 함께 비교하여 9개 항목 보고서를 작성합니다. AI 없이도 수치 비교와 원문 열기는 가능합니다.

04. 의료진 검토

인용문과 원문, 대상 성별·검사 방식·연구 조건을 확인하세요. 인용문이 원문에 있다는 사실만으로 임상적 적합성이 보장되지는 않습니다.

Dropbox의 다른 검진 기록은 아직 연결하지 않았습니다. 현재 버전은 개별 업로드 방식입니다.
