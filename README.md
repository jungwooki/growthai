# MPS Growth — 초음파 영상 비교 판독 워크스페이스

메모와 척골·요골·대퇴골 원위부 초음파 사진을 입력하면 제공된 참고자료의 실제 페이지 이미지와 비교하여 의료진 검토용 보고서를 작성합니다. 2026-09-23에 영상 비교 기능과 9개 항목 보고서를 추가했습니다. 기존의 문자 추출 전용 제한을 제거했습니다.

## 실행과 사용

1. `시작.command`를 실행하고 http://127.0.0.1:8093 에 접속합니다. 화면은 이 폴더의 `index.html`입니다.
2. `검진 메모 붙여넣기`에 복사한 기록을 넣고, 자동 입력값과 검사일을 확인합니다.
3. 척골·요골·대퇴골 원위부별 3–5장의 사진을 넣습니다. 추가 사진·PDF·메모를 함께 넣을 수 있습니다.
4. 여러 시점의 신장 기록이 있으면 `날짜별 신장 기록`에 한 줄씩 `2026-04-30 154.2 cm` 형식으로 입력합니다. 실제 날짜를 사용해 구간별·전체 연환산 성장속도를 계산합니다.
5. `AI 초음파 영상 판독 및 보고서 요청`과 자료 전송 확인을 선택한 뒤 `AI 영상 판독 요청`을 누릅니다. AI 옵션을 끄면 기본 수치만 계산합니다.
6. 9개 항목 결과와 원문 근거를 검토하고 필요하면 PDF/JSON으로 저장합니다. 다음 환자는 `새 검사`로 초기화합니다.

서버를 종료하려면 터미널에서 Control+C를 누릅니다. 코드 변경 후에는 서버를 재시작하고 브라우저를 새로고침합니다. 입력과 첨부파일은 새로고침하면 사라지므로 결과를 먼저 내려받으세요.

## 설정

`.env`의 `OPENAI_API_KEY`와 `OPENAI_MODEL`을 서버가 읽습니다. 기본 모델은 `gpt-4.1`입니다. API 키를 브라우저 코드나 Git에 넣지 않습니다. 키 변경 시 서버 재시작이 필요합니다.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
# .env가 없을 때만:
cp .env.example .env
.venv/bin/python -m uvicorn server:app --host 127.0.0.1 --port 8093
```

## 판독 처리

- 11개 원본을 `data/sources/`에 보관합니다. SHA-256과 종류는 `data/manifest.json`에 있습니다.
- PDF 411쪽 중 268쪽을 텍스트 검색합니다. 텍스트가 적은 페이지도 고정 참고영상 선정 대상이면 실제 페이지를 렌더링하여 AI에 전달합니다.
- 성별에 맞는 6–16세 요척골 참고영상 전체를 포함하여 역연령이나 이전 골연령 근처만 비교하는 편향을 줄입니다. 연구 제안의 한계, RUF 측정 설명, 점수표, 일부 성별 일치 강의 사례 및 검색된 관련 원문을 함께 전달합니다.
- 남아 기준 참고 페이지 이미지 18쪽, 여아 기준 15쪽을 포함합니다. 전체 411쪽을 매번 전달하는 것은 아닙니다. 외부 의학 웹 검색은 하지 않습니다.
- 환자 파일은 `PATIENT_FILE Fxx`, 참고 페이지는 `REFERENCE_PAGE Rxx:pN`으로 구분합니다. 현재 영상 관찰, 참고영상 비교, 과거 회차 기록을 분리하도록 지시합니다.
- 현재 영상의 골단·골화 중심·연골/성장판·capping 등 관찰 가능한 특징을 서술하고 잠정 골연령과 범위를 제시합니다. 대퇴골을 요척골 표로 임의 환산하지 않도록 지시합니다.
- 날짜가 없는 신장 기록이나 기재되지 않은 D/d·RUF·골격근량·Tanner·고환용적을 만들지 않도록 합니다. 이전 예측키를 새 예측으로 그대로 복사하지 않습니다.
- PHV 단계 번호는 제공 자료에 해당 분류체계 정의가 있어야 하며 Tanner Stage와 구별합니다. 최종키는 원문 공식 기반 계산과 제공 자료에 근거한 AI 종합 추정을 구분합니다. 약 3cm 중심 구간은 불확실성에 따라 넓힐 수 있으며 pre-PHV·가속기에만 중간값 −1.5~+5.5cm 사용자 운영 범위를 별도 표시합니다. 통계적 신뢰구간은 아닙니다. 자료가 부족하면 해당 항목을 보류합니다.
- 분석은 AI 요청 1회입니다. 여러 첨부사진의 일관성 비교를 3회 독립 판독으로 표현하지 않습니다.

보고서 항목:

1. 자료 점검
2. 초음파 부위별 해석과 사진별 관찰
3. 종합 뼈나이 추정
4. PHV 단계 판정
5. 예상 최종키
6. 해석 근거
7. 한계와 불확실성
8. 추적 관찰 제안
9. 스포츠과학 × 스포츠한의학 융합 성장평가

텍스트 인용은 원문과 공백 정규화 대조를 하며, 그림 인용은 실제 전달된 페이지인지 검사합니다. 그림 인용의 의미 일치까지 자동 검증한 것은 아닙니다. 없는 파일·부위 불일치·전달하지 않은 참고페이지를 인용한 항목은 제외하거나 보류합니다. 수치의 유효범위와 순서도 검사합니다. 이런 형식 검증은 의학적 타당성 검증을 대신하지 않습니다.

## 메모와 파일 제한

메모에서 이름·성별·생일·부모 신장·신장·체중·체지방률·ECW-Ratio, 이전 골연령·Stage·예측키를 자동 인식합니다. `12년 8개월`은 이전 골연령 152개월로 보관하며 이번 골연령으로 대체하지 않습니다. 이전 항목을 감지하면 2회차를 제안하되 실제 회차로 수정할 수 있습니다. 검사일이 없으면 직접 선택해야 합니다. 단위가 잘못되거나 같은 항목이 중복되면 확인을 요청합니다.

초음파 부위별 최대 5장, 추가자료 최대 10개, 파일당 15MB·합계 120MB입니다. 이미지와 PDF 시각 페이지는 합계 30개까지 처리합니다. 검진 PDF는 최대 40쪽이며 스캔이나 이미지가 있는 페이지를 시각 입력으로 전달합니다. PDF 텍스트는 80,000자, TXT는 30,000자까지입니다. PDF·JPG·PNG·WEBP·UTF-8 TXT를 지원합니다.

## 수치 비교

제공된 2017 성장도표의 성별·완료 월령 행에서 신장·BMI 백분위 구간을 직접 비교합니다. 백분위를 보간하지 않습니다. 신장 기준표 범위는 0–227개월, BMI는 24–227개월입니다. 기준행 밖은 비교를 보류합니다.

BMI는 kg/m², 성장속도는 `(신장 차이 / 실제 일수) × 365.2425`입니다. 날짜별 기록을 넣으면 처음 기록부터 현재까지의 전체 속도와 구간별 속도를 함께 제공합니다. 이 수치만으로 PHV를 확정하지 않습니다. 3세 이후 신장 3·50·97백분위 곡선을 표시합니다.

## 해석의 한계

이 앱은 임상 검증된 자동 골연령 진단기기가 아닙니다. 일반 영상언어모델이 사용자 제공 연구·강의자료와 초음파를 비교한 잠정 판독 초안입니다. 골연령 추정범위는 검증된 통계적 신뢰구간이 아니며, 영상 화질·단면·부위·참고자료 간격에 따라 추정이 달라질 수 있습니다. 전문 의료진이 원본과 기준을 확인하고 최종 판단해야 합니다. 인용이 있다는 사실만으로 그 자료의 임상적 타당성이나 환자 적용성이 입증되지는 않습니다.

## 데이터 처리

AI를 요청하면 현재 사진·검진기록·수치·참고자료의 원문과 페이지 이미지가 OpenAI로 전송됩니다. UI에서 전송 확인이 필요합니다. 이름·생일·코드는 구조화 입력에서 제외하고 붙여넣은 메모의 명시적 이름/생일 항목도 제거합니다. 파일·사진·자유 메모의 개인정보를 완전히 익명화하는 기능은 아닙니다.

`store: false`로 요청하지만 이것이 제공자의 모든 데이터 보관 정책을 제거한다는 의미는 아닙니다. 앱에는 검진자료의 영구 저장소를 만들지 않았으며, 큰 업로드 처리에는 운영체제 임시파일이 사용될 수 있습니다. 사용자가 내려받은 결과는 선택한 위치에 저장됩니다. 프로젝트가 Dropbox 폴더에 있으므로 `.env`와 근거 사본은 Dropbox 동기화 설정을 따릅니다.

```sh
.venv/bin/python -m pip install pytest playwright
.venv/bin/python -m pytest tests -q
node --test tests/memo-parser.test.cjs
# 서버 실행 후 macOS Google Chrome으로 로컬 UI 검증
.venv/bin/python tests/browser_intake.py
.venv/bin/python tests/browser_vision.py
# 선택: 실제 API에 합성된 빈 이미지와 가상정보만 전송하는 유료 API 연결 검사
.venv/bin/python tests/live_synthetic_vision.py
```

서버·메모·파일 그룹·근거 인용·참고영상 선택·추정 보류 규칙을 테스트합니다. 실제 API에서 가상 이미지 입력과 9개 항목 구조화 응답을 확인했고, 의료영상이 아닌 빈 이미지를 골연령·PHV·최종키로 판독하지 않는지 확인했습니다. 실제 환자 영상의 판독 정확도와 재현성은 아직 검증하지 않았습니다.

API 구현 참고: [OpenAI 공식 이미지 입력](https://developers.openai.com/api/docs/guides/images-vision), [구조화 출력](https://developers.openai.com/api/docs/guides/structured-outputs). 의학적 근거 목록에는 포함하지 않습니다.

별도 웹주소 배포 파일은 유지하지만 현재 작업은 로컬 `index.html` 화면입니다. 외부 호스팅 업로드·배포는 수행하지 않았습니다.

## 폴더 구성

- `index.html`: 기존 웹 진입 화면
- `server.py`: 실행 진입점 (`uvicorn server:app`)
- `backend/`: 서버 라우트·AI 판독·성장 이력 계산·접근 제어
- `frontend/js/`: 화면 동작·메모 파서·결과 렌더러
- `frontend/css/`: 화면 스타일
- `data/`: 원본 근거·출처 목록·검색 인덱스·성장도표
- `docs/`: 근거 및 개발 기록·배포 전환 계획
- `scripts/`: 자료 등록·배포 패키지 생성
- `tests/`: Python·JavaScript·브라우저 검사
- `artifacts/`: 로컬 검사 산출물 (Git 제외)

루트의 Dockerfile, render.yaml, requirements.txt는 배포 도구의 기본 탐색을 위해 유지합니다. 브라우저의 기존 JS/CSS URL은 서버가 새 위치로 연결합니다. `.env`와 근거 원본은 공개하지 않습니다.
