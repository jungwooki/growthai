# 검사 결과지 읽기와 초음파 판독

## 처리 흐름

1. 척골·요골·대퇴골 칸의 사진은 초음파 이미지 판독 대상으로 유지합니다.
2. 결과지 칸의 이미지·PDF·TXT는 별도 AI 요청으로 항목·값·단위·검사일·위치·참고범위를 전사합니다.
3. 전사가 완료되면 종합 판독 전에 원본 링크와 수정 가능한 표를 표시합니다.
   현재/과거 기록·좌우·주파수·참고범위를 구분하고, 읽기 불명확한 값은 기본적으로 제외합니다.
   사용자가 필요한 누락 항목을 추가할 수 있습니다.
4. 사용자가 포함할 값을 확인하면 초음파 사진과 확인한 수치를 종합 판독에 전달합니다.
   결과지 원본 이미지는 이 두 번째 AI 요청에 전달하지 않습니다.
   직접 입력한 신장·체중 등은 자동 변경하지 않고 충돌 시 판독에 차이를 명시하도록 합니다.

API는 multipart 및 S3 경로 모두 동일합니다. 첫 평가 응답은
`stage=review_records`와 추출 자료를 반환하며, 확인 후 Patient의 `reviewed_records`로 다시 요청합니다.
확인값은 원본 파일 ID 및 SHA-256과 연결합니다. 파일 변경·누락·중복 ID가 있으면 재확인을 요구합니다.
AI 전송 동의 없이 읽거나 판독하지 않습니다. AI를 끈 기본 수치 계산은 기존대로 동작합니다.

## 저장 및 비용

현재 추출값·수정값은 브라우저 화면 메모리에 유지합니다. 같은 파일로 판독을 재시도하면 전사 요청을 반복하지 않습니다.
파일 선택이 바뀌거나 새 검사·예시 입력·새로고침을 하면 재사용 상태는 초기화됩니다.
localStorage에 환자 자료를 저장하지 않습니다. 서버 DB를 통한 검사 이력 저장은 아직 없습니다.
완료 보고서 JSON의 `record_extraction`에 원래 읽은 값, 수정값, 추출 모델과 사용 토큰이 들어갑니다.
`reviewed_records`에는 실제 판독에 포함한 값이 들어갑니다.
추출 단계와 종합 판독 단계의 토큰은 별도로 기록합니다. 원화 추정 집계·앱 내 예산 알림·추가 승인 코드를 추가했습니다.
운영 연결 전이며, [AWS 운영 전환 준비](aws-runtime-plan.md)의 비용 가정과 한계를 참고하세요.

이 변경은 결과지 전사 후 초음파 이미지 판독과 종합 보고서를 작성하는 두 단계입니다.
초음파 소견만을 별도 AI 요청으로 먼저 생성하는 세 단계 파이프라인은 아닙니다.
의료진의 전사값 확인은 진단 정확도 검증을 대신하지 않습니다.

## 검증 범위

- 자동 테스트: 결과지만 전사, 확인 전 판독 금지, 수정값 반영, 불명확값 제외,
  변경 파일·중복 출처 차단, 동의 확인, 불완전/거부/오류 AI 응답 처리.
- 브라우저: 원본 링크, 수정·확인, 모바일, 원래 값과 수정값 기록, 재시도 전사 재사용, 새 검사 초기화.
- 합성 자료와 모의 AI로 검증했습니다. 실제 환자 자료를 외부 AI에 전송하지 않았고 임상 정확도나 실제 과금액을 측정하지 않았습니다.
- 운영 배포와 AWS/Vercel 인증 연결은 별도 미완료 상태입니다.
