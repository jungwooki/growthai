# GitHub → Vercel 전환 계획

작성일: 2026-09-23. 상태: 설계 확인 단계; 아직 배포하지 않음.

## 사용자 경험

웹주소 접속 → 아이디·비밀번호 인증 → 메모와 사진 업로드 → 평가 요청 → 결과 확인.
사용자의 Mac 서버는 필요하지 않다. 로그인은 접근 권한을 확인하며 Vercel 함수는 HTTP 요청에 따라 실행된다.

## 기존 코드를 그대로 올릴 수 없는 이유

Vercel 함수의 요청·응답 본문 제한은 4.5MB다. 현재 앱은 사진들을 하나의 multipart 요청으로 보내고 120MB까지 허용한다. 13장 업로드와 일부 참고 PDF 반환은 이 제한을 넘을 수 있다.

공식 문서: https://vercel.com/docs/functions/limitations
업로드 권장 구조: https://vercel.com/docs/errors/function_payload_too_large
FastAPI 지원: https://vercel.com/docs/frameworks/backend/fastapi

## 구현할 구조

1. 로그인 세션: 서버에서 비밀번호 확인, HttpOnly/Secure 쿠키 발급, 만료·로그아웃·로그인 시도 제한. 화면만 가리는 방식은 사용하지 않는다.
2. 검진 사진: 인증 후 한정된 업로드 권한을 발급하고 비공개 객체 저장소에 직접 업로드한다. 공개 이미지 URL은 사용하지 않는다.
3. 평가 API: 이미지 본문 대신 서버가 발급한 파일 ID를 받는다. 계정별 소유권을 확인한 뒤 파일을 읽어 현재 평가 로직으로 전달한다. 임의 URL을 받아 서버에서 내려받지 않는다.
4. 근거자료: GitHub에 공개하지 않는다. 비공개 저장소에서 필요한 원문을 읽거나 인증된 다운로드를 제공한다. 현재 data/sources는 Git에서 제외되어 있으므로 별도 이전 없이는 원문 비교가 동작하지 않는다.
5. 결과: 입력·출력 토큰과 적용 근거를 함께 표시한다. 업로드 만료·삭제 정책과 실패 시 정리를 포함한다.
6. 실행시간: 현재 AI HTTP timeout 240초에 서버 준비·원문 로딩 시간을 더해 실제 Vercel 플랜의 함수 실행시간과 비교한다. 장시간 요청이 한도를 넘으면 작업 큐 구조로 전환한다.

## 배포 범위

- 이 프로젝트만 별도 비공개 GitHub 저장소에 올린다. 상위 작업공간의 다른 프로젝트는 포함하지 않는다.
- .env, API 키, 환자자료, 로컬 산출물, 개인 경로는 업로드하지 않는다.
- API 키·인증 설정·저장소 자격정보는 Vercel 서버 환경변수로 관리한다.
- 현재 APP_USERNAME/APP_PASSWORD는 브라우저 Basic 인증용이다. 전용 로그인 페이지·세션 관리는 아직 구현되지 않았다.
- 프리뷰와 운영 환경 모두 인증을 적용한다. 인증 설정이 누락되면 비공개 자료 접근을 차단한다.

## 배포 전 확인

로그인 실패·만료·로그아웃, 비인증 API 차단, 다른 계정 파일 접근 차단, 13장 직접 업로드, 평가 완료, 큰 PDF 열기, 업로드 정리, 키가 브라우저에 전달되지 않음, 함수 용량·실행시간을 확인한다.

## 필요한 외부 설정

GitHub 저장소 주소, 연결할 Vercel 프로젝트, 비공개 객체 저장소 설정, 로그인 계정의 서버 측 설정이 필요하다. 비밀번호와 API 키는 대화에 붙여넣지 않고 배포 환경변수에서 설정한다.
