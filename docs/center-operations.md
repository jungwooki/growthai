# MPS 인증센터 Growth AI

등록 대상은 해온한의원 신도림 서울R&D센터(`seoul-rnd`, 서울), 해온한의원 동탄 경기화성동탄센터(`gyeonggi-dongtan`, 경기)다. 본부 계정은 환자 판독 화면 없이 사용량·예산 관리 화면을 이용한다.

## 구현과 배포 상태

- `@HAEONEMR/src/views/gateway.html`에 Growth AI 입구를 추가하고 생성 파일 `index.html`도 빌드했다. 기존 서비스와 가이드 입구를 유지한다. 링크는 현재 Growth AI 주소 `https://growthai-two.vercel.app/#login`이다. AWS 주소가 확정되면 이 링크도 변경해야 한다.
- Growth AI 로그인은 서버에 등록된 계정으로 센터와 본부 권한을 결정한다. 브라우저에서 센터를 선택하거나 요청 파라미터를 바꿔 다른 센터로 기록할 수 없다.
- 본부는 `/headquarters`에서 월별 센터·지역 집계와 CSV를 확인한다. 센터는 본인 사용량만 확인하며 전역 예산을 볼 수 없고 승인할 수 없다.
- 원본 업로드 경로는 `exams/{center_id}/{exam_id}/...`이다. 업로드 티켓은 센터와 로그인 세션에 묶인다. 본부는 이 앱에서 원본 조회·판독 권한이 없다. AWS 운영자 권한은 별개다.
- 이 변경은 로컬 구현이다. 세 계정의 비밀번호 해시와 서명 키는 로컬 비밀 설정 파일에 생성하고 인증 검증했다. 운영 환경변수, 사용량 저장소 연결 및 양쪽 사이트 배포는 아직 완료되지 않았다. 기존 운영 주소에 자동 적용되지 않는다.

## 계정 설정

`python scripts/configure_centers.py`를 실행하면 본부 `jrgoldenage`, 서울 `ljw0001`, 경기 `dongtan`의 비밀번호를 대화형으로 입력받는다. 비밀번호는 16자 이상이며 평문 대신 PBKDF2-SHA256 해시를 저장한다. 생성되는 `.env.centers.local`은 Git에서 제외한다. 이 파일은 자동 로드되지 않는다. 배포 담당자가 `APP_CENTER_AUTH_JSON`, `APP_SESSION_SECRET`을 운영 환경변수로 연결해야 한다. 파일 전체나 비밀번호를 채팅·문서·Git에 올리지 않는다.

센터 계정 모드에서는 기존 공용 `APP_USERNAME/APP_PASSWORD` 로그인이 비활성화된다. 계정 비활성화는 해당 사용자의 `active:false`로 설정하고 재배포한다. 비밀번호 해시 또는 서명 키를 바꾸면 기존 세션을 무효화한다. 세션은 최대 8시간이며 운영 환경은 HTTPS가 필요하다. MFA·SSO·셀프 비밀번호 재설정·계정 관리 UI는 포함하지 않는다.

필수 연결: `BUDGET_STORAGE=s3`, 기존 비공개 S3 설정과 읽기/조건부 쓰기 권한, `MEDIA_SIGNING_SECRET`, AI 키 및 허용 호스트. 센터 계정 모드에서 사용량 저장소를 연결하지 않으면 유료 AI 요청을 보내지 않는다. `.env.example`의 나머지 비용 설정을 함께 적용한다.

## 집계 정의

한국 시간 기준 요청 시작 월에 AI 호출을 기록한다. 결과지 읽기와 종합 판독을 분리하며, 재시도·재판독은 각각 호출로 집계한다. **환자 수, 고유 검사 수, 의료진 최종 확정 건수가 아니다.** 완료 횟수는 해당 단계 응답의 구조 검증을 통과한 횟수다. 정상 과금 응답이라도 형식 검증 실패 시 비용과 호출 수는 기록하되 완료로 세지 않는다. 같은 완료 기록을 재저장해도 중복 가산하지 않는다.

센터·지역·단계·호출 시간·토큰 사용량·추정 비용·완료 여부만 비용 원장에 저장한다. 환자 이름·회원번호·이미지·결과 수치는 저장하지 않는다. 월간 화면은 등록 센터가 사용하지 않았을 때 0으로 표시하며, 저장소 오류를 0으로 숨기지 않는다. 도입 전 센터 없는 기록은 본부에서 '센터 지정 전 사용'으로 표시한다. 과거 기록이 없는 기간을 소급 복원하지 않는다. 통계 표시 이름·지역은 현재 센터 등록 정보를 따르며 삭제된 센터는 당시 호출 메타데이터를 이용한다.

API 실패·시간초과로 비용이 미확정인 호출은 예비금과 확인 대기로 남는다. 자동 환급·자동 정산 기능은 없다. 비용은 AI 사용량 환산 추정치이며 AWS·Vercel 실제 청구액이 아니다. 본부 예산 패널은 조회한 과거 월과 관계없이 **이번 달** 예산을 관리한다. 월 5만 원은 기본 목표이며 청구 상한 보장이 아니다. 예산 추가 승인만으로 판독을 자동 재실행하지 않는다.

S3 월별 원장에는 4MB 상한이 있다. 센터가 늘어 원장 한도에 가까워지면 원장 분할 또는 데이터베이스로 이전해야 한다. 현재 구조는 보고서 영구 보관·환자 이력 공유 기능을 추가하지 않는다.

## 운영 연결 순서

1. 센터·본부 계정을 생성하고 비밀 환경변수를 연결한다.
2. Growth AI 운영 서버에 센터 모드·비공개 업로드·사용량 저장소를 함께 배포한다.
3. 합성 자료로 각 센터 로그인, 교차 접근 차단, 월간 집계를 검증한다.
4. 확정된 Growth AI 주소로 HAEON EMR 입구를 연결하고 배포한다.

추가 요금제 구매나 유료 AI 호출은 이 로컬 검증 과정에서 실행하지 않았다.
